linkedin-agent — процесът на терминалната сесия

Вход: $ linkedin-agent (= python -m src.cli, без подкоманда) Ядро: src/repl.py::Repl Влиза в: src/pipeline/runner.py::run_pipeline()

Точният процес, който тръгва, когато напишеш linkedin-agent в терминала — цикълът, който чете твоите редове, решава кога да повика конвейера за генериране, и как връща резултата. Ръчно построена с HTML/CSS/SVG — рисунка, не диаграмен код, за да се вижда винаги коректно.

Цвят стъпка на сесията детерминирана логика резултат от конвейера разклонение / въпрос към човека изход / грешка странична команда (/revise, /again)
