# PRD-1 — LinkedIn Агент за ИКТ Клъстер – Варна

**Консолидира:** research-plan-1 до 9 · concepts/strategy-1 и 2 · technical/process-1
**Дата:** 2026-08-07 · **Статус:** планиране, преди изграждане
**Правило:** тази версия не се редактира. Промяна → нов файл `prd-2.md`.

---

## 1. Резюме

Специализиран ИИ агент, изграден само за ИКТ Клъстер – Варна, който управлява публичното присъствие на организацията в LinkedIn: решава за какво да пише, генерира текст в гласа на клъстера, прави визуали, публикува през официалния LinkedIn API, измерва резултата и се учи от него. Работи на собствен сървър, с локален езиков модел — нищо от корпоративните данни не напуска инфраструктурата на клъстера.

---

## 2. Проблем и цел

Клъстерът публикува рядко и без система; форматът е почти изцяло „текст + сурови снимки от събитие" (потвърдено от прегледа на реалния feed). Целта не е бот, който постира — а актив: корпус от знания за клъстера (глас, история, членове, стратегия), който расте и се подобрява във времето, под пълен контрол на организацията.

## 3. Обхват на продукта

| Способност | Кратко |
|---|---|
| Откриване на съдържание | Сайт, календар, повтарящи се рубрики, членове |
| Ръчен бриф | Човек описва тема; агентът допълва стилово, никога фактически |
| Писане | Локален модел, гласът на клъстера, факт-проверка спрямо корпуса |
| Визуализация | Шаблонен рендер в бранда (основно); генеративни изображения по избор, по-късно |
| Одобрение/автономност | Матрица по тип съдържание, избираема от панел |
| Публикуване | Официален LinkedIn API, включително коментари, анкети, документи |
| Измерване | Метрики +7 дни, месечен отчет |
| Самоусъвършенстване | „Сънуване" — предложения от анализ на резултатите, никога автоматично приложени |

## 5. Функционални изисквания по модул

| Модул | Изисква се да |
|---|---|
| `collectors/` | Открива нови новини, събития, поводи от рубрики автоматично, ежедневно |
| `input/brief.py` | Приема ръчен бриф; разграничава стилов пропуск (допълва) от фактически (пита, не измисля) |
| `writer/` | Генерира 2–3 варианта, използва 5–8 релевантни примера от корпуса, проверява факти |
| `visual/` | Рендерира изображение по шаблон от `knowledge/visual/`, чете снимки от Nextcloud папка |
| `policy/` | Детерминистични правила + LLM класификатор; решава ефективното ниво на автономност |
| `approval/` | Опашка, избирач на ниво по тип, известяване, достъп извън офис мрежата (подписан линк) |
| `publisher/` | Публикува през LinkedIn API; draft режим преди одобрен достъп |
| `reflect/` | Задейства се при нови метрики (не на таймер); предлага промяна в стратегията; никога не прилага сама |
| `analytics/` | Сваля метрики +7 дни; месечен отчет |

## 6. Нефункционални изисквания

| Категория | Изискване |
|---|---|
| GDPR | Нищо лично не напуска сървъра без нужда; забрана за имена на непълнолетни в автоматичен път; снимки локално (Nextcloud), не в чужд облак |
| EU AI Act, чл. 50 (в сила от 2.08.2026) | Оповестяване на ИИ-генерирано съдържание — в „About" на страницата и при генеративни изображения |
| LinkedIn ToS | Само официален API; забрана за browser-use автоматизация — потвърдено с 2026 данни за засилено засичане |
| Сигурност | Kill switch, дневен/седмичен таван на публикации, circuit breaker при последователни грешки |
| Одитируемост | Единен одитен журнал — всяко решение (одобрение, промяна на ниво, приложено предложение) се записва |
| Поддръжка | Обяснимо за не-технически ръководител; технически човек трябва само за код промени |

## 7. Технически стек

| Слой | Избор |
|---|---|
| Език / уеб | Python 3.12+, FastAPI |
| База данни | SQLite + SQLAlchemy |
| Планировчик | APScheduler (cron + събитийни тригери) |
| Модел | Ollama, локален (BgGPT/Qwen кандидат) |
| Рендер | Playwright (headless Chromium) |
| Снимки | Nextcloud, self-hosted |
| Тестове | pytest, приоритет: `policy/autonomy.py` |
| Разгръщане | Docker, един под |

Пълна схема на данните и endpoint-и: [technical/process-1.md](../technical/process-1.md).

## 8. Автономност — режими (v1)

| Ниво | Поведение | Пример за тип |
|---|---|---|
| Одобрение | Чака изрично „да" | Пост за член на клъстера |
| Възражение | Публикува, ако никой не възрази до 48ч | Преразказ на новина от сайта |
| Автономно | Публикува веднага | Рубрика по график, напомняне за събитие |

Пълната 6-степенна матрица (L0–L5) е проектирана и остава достъпна за растеж — v1 стартира с трите практични нива по-горе. Промяната на ниво е избираема от панела, записва се в одитния журнал; автоматично понижаване при всеки инцидент.
